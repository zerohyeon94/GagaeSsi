## 1. 목적

과거 소비를 날짜별로 탐색하고 잘못 입력한 기록을 수정·삭제한다. 현재는 오늘 기록만 조회/수정 가능.

## 2. 결정

| 항목 | 선택 |
|---|---|
| 배치 | **새 "내역" 탭** (홈·기록·내역·통계·설정 5탭) |
| 과거 수정 시 이월 | **전체 정확 재계산** (전액/분리 모드 + 모아둔 이월금 풀 포함) |
| 데이터 | 신규 엔티티 없음(`SpendingRecord` 날짜 조회). createdAt/updatedAt은 범위 제외 |

## 3. 화면 (`HistoryView`)

- 상단: 월 이동 + 그 달 소비 합계
- 중단: **월간 캘린더** — 날짜별 총소비 · 기록 존재 점 · 예산 상태 색(여유/근접/초과)
- 하단: **선택 날짜 소비 목록** (기존 소비 행 재사용) → 탭 시 수정 시트, 삭제
- 수정/삭제 전 안내: "이 기록을 바꾸면 이후 사용 가능 금액과 이월금이 다시 계산됩니다."

## 4. 이월 체인 재계산 (핵심)

`CoreDataManager.recalculateCarryOverChain(from:)` — 수정/삭제된 소비 날짜부터 오늘까지:
- 각 날의 **일자 이월**(전날→그날 `CarryOverSource`, `date < 그날`)과 **분리 모드 풀 적립**(양수 `CarryOverPoolEntry`, `date == 그날`)만 삭제 후, `processDailyBudgets`와 동일 규칙으로 재생성.
- **인출·환급 크레딧**(`date == 그날`)과 **위시 저금**은 건드리지 않음(날짜·부호로 구분).
- 순차 처리(이른 날 → 오늘)로 각 날이 갱신된 전날 잔액을 반영.

편집/삭제 시점: 내역 탭에서 과거 기록을 수정/삭제한 뒤 호출. 오늘 기록 편집(`SpendView`)은 이후 날짜가 없어 재계산 불필요.
