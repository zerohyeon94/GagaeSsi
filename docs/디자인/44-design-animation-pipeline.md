# 디자인·애니메이션 공통 파이프라인 (#44)

작성일: 2026-11-03 · 상태: **결정, 착수는 출시(#26 · #27 · #28) 이후**

이후 Android 앱까지 고려해, 디자인과 캐릭터 애니메이션을 플랫폼별 코드가 아니라 **공통 원본 파일**로 관리한다.

## 1. 결정

```
Claude 디자인 ──▶ Figma ──┬─▶ iOS (SwiftUI)        ← 화면·토큰
 (시안·탐색)    (원본)    ├─▶ Android (Compose)
                         └─▶ Rive / Lottie ──▶ 양쪽 공통 .riv / .lottie
```

| 단계 | 역할 | 결과물 |
|---|---|---|
| Claude 디자인 | 화면 시안, 캐릭터 방향 탐색, 여러 안 비교 | 시안 (확정 전) |
| Figma | 확정안의 **원본**. 토큰·컴포넌트·캐릭터 파츠 | Figma 파일 |
| Rive | 예산 상태에 **반응하는** 캐릭터 (돼지 표정·전환) | `gagaessi_pig.riv` |
| Lottie | 정해진 **일회성 연출** (급여일 축하, 온보딩, 로딩) | `*.lottie` |
| 앱 | 같은 Figma 값, 같은 애니메이션 파일을 쓴다 | iOS·Android가 같은 모습 |

- 정적 디자인의 기준은 Figma, 움직임의 기준은 `.riv`/`.lottie`다. 코드는 이 둘을 따른다.
- 기존 원칙은 그대로다: 색은 `DesignSystem.swift` 토큰, 글꼴은 SF Pro Rounded (`6-brand-style-guide.md`).

### Rive와 Lottie를 나누는 기준

| | Rive | Lottie |
|---|---|---|
| 상태 전환 | State Machine이 파일 안에 있어 앱은 값만 넘긴다 | 앱이 마커 구간을 골라 재생한다 |
| 맞는 용도 | 상태에 따라 계속 반응하는 캐릭터 | 처음부터 끝까지 정해진 연출 |
| 런타임 | `rive-ios`, `rive-android` | `lottie-ios`, `lottie-compose` |

돼지는 예산 상태(여유·주의·위험·소진)에 따라 바뀌므로 Rive를 쓴다.

## 2. Figma 구성 규칙

- **변수**: `DesignSystem.swift`의 색 토큰을 같은 이름의 Figma 변수로 만들고, 라이트/다크를 변수 모드로 나눈다. 코드와 Figma에서 토큰 이름이 같아야 한다.
- **캐릭터 파츠**: 머리, 귀(좌·우), 눈썹(좌·우), 눈, 코, 입, 볼, 땀을 각각 별도 레이어로 둔다. 귀는 밑동, 눈썹은 가운데를 회전 기준점으로 정한다.
- **상태별 프레임**: 여유, 주의, 위험, 소진 표정을 나란히 두어 Rive 작업의 기준 그림으로 쓴다.

## 3. Rive 캐릭터 규칙

State Machine 이름 `Mood`, 입력 이름은 플랫폼 공통이다.

| 입력 | 타입 | 값 |
|---|---|---|
| `mood` | Number | 0 여유 · 1 주의 · 2 위험 · 3 소진 (`BudgetStatus`와 대응) |
| `tap` | Trigger | 눌렀을 때 반응 |

상태마다 반복 애니메이션(idle)을 하나 두고, 상태 사이 전환 애니메이션을 따로 만든다.

### 표정 기준

| 상태 | 귀 | 얼굴 | 몸·색 | 반복 동작 |
|---|---|---|---|---|
| 여유 | 쫑긋 | 웃음, 반짝 눈 | 기본 분홍 | 통통 튀는 숨쉬기 |
| 주의 | 옆으로 접힘 | 처진 눈썹, 물결 입 | 땀 한 방울 | 느린 숨, 땀 흐름 |
| 위험 | 뒤로 붙음 | 동그랗게 뜬 눈, 벌린 입 | 이마부터 파랗게 질림 | 부들부들 떨림 |
| 소진 | 축 늘어짐 | X 눈, 혀 | 채도 낮아짐 | 주저앉은 채 정지 |

### 움직임 원칙

- **시차**: 귀 → 눈썹 → 입 → 땀 순서로 움직인다. 한꺼번에 움직이지 않는다.
- **빠른 반응, 느린 감정**: 놀람(귀)은 약 0.2초 스프링, 감정(눈썹·입)은 0.5~0.8초.
- **은은한 idle**: 홈에 항상 떠 있으므로 2~4초 주기의 작은 움직임만 넣는다.
- **동작 줄이기**: 시스템 "동작 줄이기"가 켜져 있으면 전환 없이 표정만 바꾼다.
- **작은 크기에서도 읽히게**: 얼굴만이 아니라 귀·자세·색으로 상태를 보여 준다.

### 색

캐릭터 색은 토큰(gagaePink 계열)에서 가져온다. 라이트·다크 양쪽에서 보이는 중간 톤으로 정해 파일 하나로 쓰는 것을 기본으로 하고, 나눠야 할 때만 런타임에서 색을 바꾼다 (Rive 데이터 바인딩, Lottie 동적 속성).

## 4. 앱 연결 (예시)

```swift
// iOS — rive-ios
@State private var pig = RiveViewModel(fileName: "gagaessi_pig", stateMachineName: "Mood")

pig.view()
    .onChange(of: status, initial: true) { _, s in
        pig.setInput("mood", value: Double(s.moodIndex))
    }
```

```kotlin
// Android — rive-android
riveView.setNumberState("Mood", "mood", status.moodIndex.toFloat())
```

- `.riv`/`.lottie` 파일은 리포에 넣고 변경 이력을 남긴다.
- `moodIndex`는 아직 없는 이름이다. 연결할 때 `BudgetStatus`에 추가한다.

## 5. 진행 순서

1. Claude 디자인으로 화면·캐릭터 시안 탐색
2. Figma: 토큰 변수(라이트/다크), 캐릭터 파츠 레이어, 상태별 표정 프레임
3. Rive: 여유 ↔ 주의 하나만 먼저 만든다 (요금제·내보내기 제한은 시작 전에 확인)
4. iOS 홈 카드에 붙여 실기기에서 크기·동작 줄이기 확인
5. 위험·소진, Lottie 연출(급여일 축하 등)로 확장
6. Android 착수 시 같은 파일 사용

## 6. 참고

- 2026-11-03에 SwiftUI 코드만으로 만든 돼지 시안(픽셀 아트 vs 벡터, 여유 → 주의 전환 GIF)으로 방향을 확인했다. 벡터 쪽이 앱 분위기와 애니메이션 확장성에 더 맞았다. 시안 코드는 리포에 넣지 않았다.
