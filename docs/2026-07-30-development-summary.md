## 1. 이번 개발 사이클 요약

사용자가 정리해 온 아이디어들을 브레인스토밍 스킬로 설계 확정 → TDD 구현 → 커밋/푸시 → 노션 반영까지 일관되게 진행했다. **총 15개 항목 완료, 전체 테스트 82개 통과.**

각 기능은 `docs/superpowers/specs/`에 설계 문서가 있고, 노션 "앱 문서 관리" DB에 요약+GitHub 링크가 등록돼 있다.

## 2. 완료된 기능

### 버그 수정
- **데이터 초기화 행 탭 영역** — 행 전체 탭(`contentShape`).
- **온보딩 급여일 칩 자동 스크롤** — 기본 25일이 화면 밖에 숨던 문제.
- **급여일 말일 보정 (P0)** — 29~31일 설정 시 날짜 오버플로. 주말 보정과 함께 해결.

### 예산 계산 엔진
- **주말 급여일 보정** — 급여일이 주말이면 직전 금요일 기준(`effectivePayday` + 3개월 브래킷팅).
- **이월 방식 선택** — 전액 이월 / 모아둔 이월금 분리(양수는 풀 적립·꺼내 쓰기, 음수는 페널티 이월).
- **변동 고정비 (Phase A+B)** — 관리비/금리/환율 등. 예상액 배분 + 지출일 확정금액 입력 → 그날부터 재계산. 지출일 오전+오후 재알림, 홈 미확정 배너.
- **할부 처리** — 총액/개월수 → 활성 개월 동안 월 납입액을 하루 예산에서 미리 차감. 자동 종료.
- **페이백/환급** — 지출은 전액 기록, 환급 예정 필드 + "환급 받음" 시 오늘 예산에 +크레딧. 통계 순 지출 표시.

### 고정비
- **종류 분리 (지출/저축/투자)** + **고정/변동 자동 분리, 변동은 결제일 순** — 종류별 breakdown으로 "순수 지출" 부담 완화. 예산 계산은 동일(모두 차감).

### 소비 기록 · 통계
- **결제 시간대 리포트** — 실제 시각 보존 + 오전/점심/저녁/심야 4구간.
- **소비 항목 자동완성** — 기존 기록 기반 추천 칩, 항목명+최근 카테고리 자동 입력.

### 위시리스트
- **위시리스트 저금 (v1.2)** — 위시 아이템·일일 저금·D-day·게이지·환급 + **희망/필수(want/need)** 구분.

## 3. 아키텍처 메모 (이번 사이클에서 확립된 패턴)

- **순수 로직 분리 + TDD**: 날짜/금액 계산은 순수 함수(`DailyBudgetCalculator`, `TimeSlot`, `FixedCostGrouping`, `InstallmentModel`, `SpendingSuggestionEngine`, `VariableCostReminder`)로 분리해 인메모리 CoreData 없이 테스트.
- **"이동/약정 금액"은 소비 기록을 만들지 않는다**: 위시 저금·고정비·할부·환급 크레딧 모두 `CarryOverSource`/예산 차감으로 처리해 소비 통계 이중 계산을 방지.
- **설정 변경은 오늘부터 반영**: 과거 일자·이월 체인은 불변, 오늘 이후만 재계산.
- CoreData는 현재 모델 버전(`GagaeSsi 2`)에 lightweight migration으로 필드/엔티티 추가.
